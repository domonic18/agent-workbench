# M4 · 产出量化 + 周报 + 飞书免登

> 设计依据: [02](../../arch/02-数据服务设计.md) §3.6 ｜ [01](../../arch/01-后端服务设计.md) §3 §8 ｜ [00](../../arch/00-总体架构设计.md) §7
> 本文件只列任务与依赖,不维护进度;完成状态只写 `development-plan.md`。

| # | 任务 | 产出 | 依赖 | 验收点 |
|---|------|------|------|--------|
| M4-1 | 用量上限与硬停 | 迁移 `usage_limit` + `decide()` 用量判定 | M3-4、M2-5 | token 计数全程整数;粒度按 §9-9 = **按 Agent 的日 token 上限**(`agent_id` 唯一,含 `daily_token_limit` / `warn_percent` / `hard_stop` / `is_active`);未配上限=不限,配了读不出=deny;到警戒线告警,到硬顶由 `decide()` 前置拒绝新调用(不是只发提醒、不是跑完才算),拒绝原因写 `tool_call_log`;**不做预留**——调用前不可知 token 数,接受采集器滞后造成的超冲 |
| M4-2 | 数字下钻 | 总览 / 任务 / 周报的数字 → 会话记录 | M4-1、M3-9 | 任一指标可点到产生它的 `timeline_event` 或 `token_usage` 行 |
| M4-3 | 周报 | 定时汇总 + 飞书卡片(经发件箱) | M4-1、M2.5-3 | 自动生成、无需人工修数;投递失败进 `retry_wait` 补投,不阻塞任务;按 §9-2 先做每日汇总口径;含任务一次交付通过率(`rework_count=0` 的 done 任务占比)与平均往返轮次;token 消耗按 Agent / 项目汇总,不折算金额 |
| M4-4 | 飞书网页应用免登 | 免登接入 | M3-2、M1.5-4 | 仅覆盖**只读**;吊销凭证、删除条目等敏感操作仍需二次确认,不因换登录方式放宽 |

**纪律**: 免登只降摩擦,不降权限。凡涉及「不可逆」的操作,M4 之后仍保持二次确认。
