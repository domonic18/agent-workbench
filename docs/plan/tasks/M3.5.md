| # | 任务 | 产出 | 依赖 | 验收点 |
|---|------|------|------|--------|
| M3.5-1 | 授权屏 | `web/src/pages/Capabilities` + `components/capability/` | M2-3、M3-2 | 三视图(待批 / 生效 / 历史);批准前完整展示动作与范围,不折叠关键字段;批准后进 `issuing` 且按钮置灰;签发失败给重试入口,不显示为已生效;吊销需二次确认 |
| M3.5-2 | 知识状态机与来源字段 | 迁移 `knowledge_entry` 状态与 `source_task_id` / `source_agent_id` | M1.5-1 | 状态 `draft` / `candidate` / `active` / `archived` 合法迁移;非法跃迁被拒并有单测 |
| M3.5-3 | 知识屏 | `web/src/pages/Knowledge` + `components/knowledge/` | M3.5-2 | 默认只列 `active`;`candidate` 带数量角标;**逐条采纳,无全选批量**;`index.md` / `log.md` 只读;编辑写入 Markdown 文件而非库正文 |
| M3.5-4 | 索引链 | FTS5 + `knowledge_chunk` + `knowledge_vec`(vec0) + `embedding_status` | M3.5-2 | 重建走 worker_thread,不阻塞事件循环;`content_hash` 未变不重嵌入;`pending` / `failed` 在列表打标并可单条重试 |

| M3.5-7 | 知识验收 | 验收记录 | M3.5-6 | 「第二次不重复解释」以 `tool_call_log` 命中率证明;在 5 分钟窗口外重复测试仍可召回 |
