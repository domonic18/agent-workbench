> 设计依据: [01](../../arch/01-后端服务设计.md) §2 §3 §4 §7 ｜ [02](../../arch/02-数据服务设计.md) §3.1 §3.2 ｜ [03](../../arch/03-前端设计.md) §3 §4 §5 ｜ [04](../../arch/04-采集器设计.md) 全篇
> 本文件只列任务与依赖,不维护进度;完成状态只写 `development-plan.md`。

MVP 就是本里程碑。**只读**是刻意收窄:总览与任务吃同一套采集数据,一起做最省;写操作(批准、编辑)在 M3.5。

| # | 任务 | 产出 | 依赖 | 验收点 |
|---|------|------|------|--------|
| M3-1 | 采集与投影表 | 迁移 `agent_run` / `timeline_event` + 事务边界 | M2.5-1 | 应用服务层开事务、仓储只构造查询、路由不碰库;`block_rev` 旧值不得覆盖新内容 |
| M3-2 | 认证与会话 | 登录 / 退出 / 会话中间件 | M1.5-1 | 口令只来自 env;Cookie `HttpOnly + SameSite=Lax`,默认 12h;非 GET 校验 `Origin` 与 `X-Requested-With`,缺失或跨站 403;写操作另需 `Idempotency-Key`;来源白名单只接受 `127.0.0.1` 与 `aw.example.com` |
| M3-3 | 采集器 | `collector/` 可执行产物 + `scripts/install-collector.sh` | M3-4 | inode + offset 断点续读;spool 上限 512MB;心跳 30s;ACK 后才推进 offset;launchd 常驻 |
| M3-4 | 采集入库 | `POST /api/ingest` + `ingest_receipt` | M2.5-5 | Bearer 采集器密钥校验;去重键 `(collector_id, stream_id, seq)`;7 天窗口滚动清理;重复推送返回首次结果 |
| M3-5 | 读模型投影 | 总览聚合 + 任务时间线 + 作用域 `revision` | M3-1 | `revision` 每作用域单调递增;总览五项指标(运行 Agent / 运行任务 / 今日成本 / 待确认 / 心跳超时)可一次取回 |
| M3-6 | SSE 实时 | `GET /api/stream` | M3-5 | 首帧必为 `snapshot`;`delta` 严格递增;心跳 20s;`client_id` 上限 10,超限 429;缺口检测→重新拉快照 |
| M3-7 | A2A 线程读取 | `GET /api/tasks/:id/a2a` | M2.5-4 | 按 `round` 升序;同一条消息多次重投只返回一行最新投递状态;`ack_at` 空表示未确认;不返回任何证书内容 |
| M3-8 | Web 总览屏 | `web/src/pages/Overview` | M3-5、M3-6 | 一行一 Agent;状态颜色 + 文本双编码;离线超 5 分钟标注「心跳超时」;空态给「采集器未上报」排查提示,不显示假数据;密钥入口仅显示一次 |
| M3-9 | Web 任务屏 + 抽屉 | `web/src/pages/Tasks` + `components/task/` | M3-6、M3-7 | 筛选反映到 URL query;抽屉含时间线(按 `seq`)与 A2A 线程;「最后一条事件 + 阻塞原因 + 已等待时长」直接可见 |
| M3-10 | 移动适配与双机验收 | 响应式 + 验收记录 | M3-8、M3-9 | 375pt 起可用;表格转卡片保留三列;抽屉改全屏;触控 ≥44px;移动网络首屏 3 秒内可交互;两台机会话数据齐全 |

**口径约束(M3-2)**: 登录失败锁定窗口为「5 次锁 10 分钟」,会话寿命 12 小时(与需求 7 天滑动的差异属有意收紧);依据见 [01](../../arch/01-后端服务设计.md) §3 注,代码不得另立数值。

**不做**: 图表库、`setInterval` 轮询列表、对话主入口、任务详情里的重发 / 取消干预(尚未建模)。
