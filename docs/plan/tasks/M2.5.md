# M2.5 · A2A 通道（传输层）

> 上位: [../development-plan.md](../development-plan.md) ｜ 出口标准: Agent 间往返脱离飞书群;跨机可达;离线消息不丢且不重复执行
> 设计依据: [01](../../arch/01-后端服务设计.md) §5 §5.1 §6 ｜ [02](../../arch/02-数据服务设计.md) §3.3 §3.7
> 本文件只列任务与依赖,不维护进度;完成状态只写 `development-plan.md`。

| # | 任务 | 产出 | 依赖 | 验收点 |
|---|------|------|------|--------|
| M2.5-1 | 身份域:机器与 Agent 注册表 | 迁移 `machine` / `agent` + `/api/agents` 注册与轮换 | M1-6、M1.5-1 | 明文 `secret` 只在注册响应出现一次;库中只有 `secret_hash`;轮换后旧密钥立即失效;Agent 与采集器两套密钥互不通用 |
| M2.5-2 | A2A 域表 | 迁移 `a2a_message` / `outbox` / `a2a_dead_letter` | M1.5-2 | 内容(`a2a_message`)与运输(`outbox`)分表;`refs` / `auth` 落 JSON 列;`auth_ticket` 只存标识 |
| M2.5-3 | 发件箱状态机 | `src/reliability/outbox/` | M2.5-2 | 7 态迁移合法;`lease_token` 条件更新,过期租约不能提交结果;`idempotency_key` 重复直接返回首次结果;业务投递 `uncertain` 围栏生效,通知投递不围栏 |
| M2.5-4 | 信箱拉取与 ACK | `/api/a2a/inbox`、`/api/a2a/inbox/:msg_id/ack` | M2.5-1、M2.5-3 | 长轮询 `cursor + wait=25s`;只返回 `to` 为本 Agent 且未 ACK 的消息,跨 Agent 403;未 ACK 在租约过期后重新可见(at-least-once);`delivered` 只以 ACK 为准 |
| M2.5-5 | Agent 侧 HMAC 鉴权 | 中间件:签名 + 时间戳(5 分钟窗口) | M2.5-1 | 采集器密钥与 Agent 检索密钥不可互换使用;重放请求被拒;缺签名 401 |
| M2.5-6 | 死信巡检与回执 | 作业 + `a2a_dead_letter` 写入 | M2.5-3 | `deadline` 过期未 ACK → `failed` + 死信 + 回执「已过期,请重新发起」;`notify` 免 `deadline`;不自动重发 |
| M2.5-7 | 跨机双机验收 | 两机往返实测记录 | M2.5-4、M2.5-6 | Agent 间往返不经飞书群;停机期间消息排队,恢复后补投;同一 `msg_id` 不重复执行 |

**不做**: 主动唤醒(`notify` 之外的 turn 注入)推迟;WorkBuddy 侧按 5 分钟上限被动轮询,长轮询优先、定时兜底。理由见需求 §7-B3。

**上线纪律**: 与 M3 配对上线。没有控制台可见消息去向之前,不切停飞书群通道。
