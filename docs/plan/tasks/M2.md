**施工前提**: M2-2 按「每 Agent 一个 bot + 每任务一个 trait」实现,证书扩展用 `role.options.cert_extensions` + `{{ external.aw_task_id }}`(不要用 `internal.*`,它不插值);本地验证脚本在 `docker/spike/`。若验收要求证书与任务强绑定,改用每任务一个 bot(对象随任务增长)。M2-5 先确认 proxy 能否以 stdio 透传 / 多路复用接管既有 MCP server(而不是逐个重写),以及 `require_approval` 挂起 300s 是否会被 Claude Code 的工具超时先掐断。

**出口标准落点**: 「高危拦截」只以 MCP 通道取证——M2-5 的 L2 覆盖测试证明未知按 L2、无审计不执行;**Claude Code 原生工具调用与终端直跑、绕开托管启动的会话不在职责边界内,列为范围外,不宣称拦截率**;「零长期凭证」以 M1-1 资源清单逐台核对作为证据,不以配置声明代替。
