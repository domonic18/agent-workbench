## 里程碑

### M0: 立项与调研(前置)

- 目标: 立项书 + 开源方案调研报告
- 验收标准: 立项书定稿;调研报告覆盖消息网关、知识检索、任务编排、可视化四条线
- 状态: **已完成**。M0-1 立项书 v0.2、M0-2 调研报告 v0.1（四线齐备、含选型结论）、M0-3 需求差异裁决（§6 差异表 + §7 B1~B8）全部落档

### M1: 资源清单 + 通道边界

- 目标: 明确线上资源清单与访问方式,定死 A/B/C 三类通道边界
- 验收标准: 服务器清单与登录方式明确;能力分级可直接落地
- 状态: **进行中,仅余 M1-3**(决策已定、实测待后端)。M1-0 / M1-1 / M1-2 / M1-4 / M1-6 / M1-7 / M1-8 已闭;M1-5 文档口径已闭,**物理就位(容器、tbot 角色、通配证书挂载、目标机 node agent)并入 M2-2 验收**——M1 阶段无后端可挂,不能声称已完成
- 阻塞项: M1-3 实测需 `aw` / `tp` 后端就绪才能加规则,不阻塞 M1.5 开工;原「资源清单明细(§12-4)」已由 M1-1 关闭;跨机通道已裁决为复用 frp(B1/B7)

### M1.5: 沟通契约(轻量版)

- 目标: 消息模板 + 必填校验 + 任务必填字段
- 验收标准: 缺必填字段的消息被拒收并提示补什么;抽检 20 条可在 10 秒内说清「谁要谁干什么、什么时候要」
- 状态: **进行中**:M1.5-1 / M1.5-2 / M1.5-3 已闭(SQLite 基线 + 单实例锁 + `/healthz` db 状态、A2A 信封校验、任务域迁移与状态机);M1.5-4 起未开
- 阻塞项: **飞书自建应用凭据**(`APP_ID` / `APP_SECRET` / `Verification Token` / `Encrypt Key`)与 `open_id` 白名单——阻塞 M1.5-4 及之后的指令链路;资源清单里目前没有任何飞书条目
- 说明: 几乎不需要新基建,但让后续环节都有结构化数据可用

### M2: 能力授权

- 目标: 基于 Teleport CE + tbot 落地 capability 审批与审计;SSH / 数据库经 15 分钟短时证书访问;审批入口先走飞书卡片
- 验收标准: 生产资源零长期凭证;高危拦截 100%;证书 TTL 15 分钟且由 tbot 自动续期;审计可追溯 task_id
- 状态: 未开始
- 阻塞项: Teleport 部署本体(容器 / tbot 角色 / 通配证书挂载 / 目标机 node agent)——由 M1-5 移交,在 M2-2 一并验收;原「资源清单明细(§12-4)」已由 M1-1 关闭
- 说明: 授权粒度定为「目标 + 动作 + 命令白名单」,解析失败即拒绝;吊销以 TTL 自然过期为主

### M2.5: A2A 通道(传输层)

- 目标: 服务端 + 信箱适配器 + 跨机通道齐备;唤醒机制推迟(WorkBuddy 先按上线补投)
- 验收标准: Agent 间往返脱离飞书群;跨机可达;离线消息不丢且不重复执行
- 状态: 未开始
- 阻塞项: 无(跨机通道已定:复用 frp;WorkBuddy 唤醒暂缓,先按上线补投)
- 说明: 与 M3 配对上线;没有 M3 就停群会让协作直接断掉

### M3: 控制台一期(总览 + 任务)

- 目标: 两类 Agent 同屏可见,只读看板优先;事实源在控制台库;每台机部署采集器
- 验收标准: 首屏 3 秒内答出「谁在跑、跑到哪、花了多少」;任一任务能回答「卡在哪一环」;手机可访问;口令登录生效;两台机的会话数据齐全
- 状态: 未开始
- 阻塞项: 采集器实现、`aw.17aitech.com` 的 DNS 与 frpc 代理、登录口令来源(§8-4)与 `open_id` 白名单(B6)

### M3.5: 控制台二期(授权屏 + 知识屏)

- 目标: 审批台搬进控制台,飞书卡片退为通知与一键跳转;kb 可浏览可重建
- 验收标准: 授权审批在控制台完成;kb 条目可读可改、索引可整库重建
- 状态: 未开始

### M4: 产出量化 + 周报 + 飞书免登

- 目标: R3 指标与成本记账、周报自动生成、飞书网页应用嵌入免登
- 验收标准: 周报自动出且无需人工修数;任一数字可下钻到会话记录;飞书内打开免登录
- 状态: 未开始
